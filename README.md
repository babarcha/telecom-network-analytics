
# Telecom Network Performance Analytics Dashboard

A Python-based data analytics project for analyzing
synthetic LTE and 5G NR network performance measurements.

## Objectives

- Generate telecom KPI datasets
- Clean and validate network measurements
- Analyze network performance using Python and SQL
- Visualize KPIs with Plotly and Streamlit
- Detect congestion and performance anomalies
- Apply automated testing and CI

## Technology Stack

Python, NumPy, Pandas, SQLite, SQL,
Plotly, Streamlit, pytest, GitHub Actions.

## Phase 1

Development environment, synthetic sample dataset,
basic KPI analysis, and dataset validation tests.

## Quick Start

Create and activate a Python virtual environment,
then install dependencies:

    python -m pip install -r requirements.txt

Generate the sample dataset:

    python -m src.first_analysis

Run the tests:

    python -m pytest -v

## Data

All network measurements are synthetic.
No operator or customer data is used.
